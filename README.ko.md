# LidLux

[English](README.md) | [한국어](README.ko.md)

[![CI](https://github.com/n3wr1ch/lidlux/actions/workflows/ci.yml/badge.svg)](https://github.com/n3wr1ch/lidlux/actions/workflows/ci.yml)

**주변 밝기에 맞춰 MacBook과 외부 모니터의 밝기를 조절하는 메뉴바 앱입니다.**

외부 모니터를 연결한 뒤 macOS 자동 밝기가 멈추는 문제를 해결하기 위해, MacBook의 내장 조도 센서를 직접 읽어 내장 디스플레이와 DDC/CI 지원 외부 모니터의 밝기를 조절합니다.

## 기능

- **조도 기반 자동 밝기:** 로그 조도 곡선과 평활화로 밝기를 부드럽게 바꿉니다. 내장·외부 자동 조절을 각각 켜고 끌 수 있습니다.
- **조도별 학습:** 자동 조절이 켜져 있을 때 밝기 키나 모니터 버튼으로 밝기를 바꾸면, 감지한 수동 조절을 해당 조도 부근의 선호로 기억합니다. **곡선당 최대 8개 지점**을 저장하고 지점 사이의 밝기를 보간합니다. 학습 곡선은 주변이 밝아질수록 목표 밝기가 낮아지지 않도록 유지합니다. 내장·외부 학습은 별개이며, 외부 모니터끼리는 하나의 학습 곡선을 공유합니다.
- **DDC/CI 제어:** 지원하는 외부 모니터의 하드웨어 밝기를 조절합니다.
- **밝기 키와 HUD:** 커서가 있는 외부 화면을 밝기 키로 조절하고, 쓰기에 성공하면 화면에 밝기 표시를 띄웁니다.
- **유휴 디밍 구분:** 자리를 비운 사이 내장 화면이 어두워진 것을 선호로 학습하거나 곧바로 되돌리지 않습니다.
- **클램쉘 일시 정지:** 덮개를 닫아 내장 화면이 비활성화되면 내장·외부 자동 조절을 멈춥니다.
- **영어·한국어 UI:** 시스템의 첫 번째 선호 언어가 한국어이면 한국어, 그 외에는 영어로 표시합니다.

## 요구 사항

- 내장 조도 센서가 있는 **Apple Silicon MacBook**.
- **macOS 13 이상.** 비공개 API에 의존하므로 [한계 및 주의 사항](#한계-및-주의-사항)을 확인하세요.
- 외부 제어에는 **DDC/CI 지원 모니터**가 필요하며, 모니터의 화면 메뉴(OSD)에서 DDC/CI를 켜야 합니다. 모니터·케이블·독에 따라 지원이 다르고, **HDMI는 기종에 따라 작동하지 않을 수 있습니다.**

## 설치

### Homebrew

```sh
brew install --cask n3wr1ch/tap/lidlux
```

업데이트는 `brew upgrade --cask lidlux`. 아래의 첫 실행·손쉬운 사용 권한 안내는 Homebrew로 설치해도 동일하게 적용됩니다.

### 릴리스 다운로드

1. [GitHub Releases](https://github.com/n3wr1ch/lidlux/releases)에서 LidLux ZIP을 내려받아 압축을 풉니다.
2. `LidLux.app`을 `/Applications`로 옮긴 뒤 실행합니다.
3. 첫 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기(Open Anyway)**를 선택하고 확인합니다.

LidLux는 로컬 임시 서명(ad-hoc)을 사용하며, **Developer ID 서명이나 Apple 공증을 받지 않았습니다.** 이 저장소에서 내려받고 릴리스 체크섬을 확인한 뒤, 다음 명령으로 격리 속성을 제거하고 다시 실행할 수도 있습니다.

```sh
xattr -dr com.apple.quarantine /Applications/LidLux.app
```

체크섬 확인 방법은 릴리스 노트에 있습니다.

### 소스에서 빌드

Apple Command Line Tools를 설치하세요. Xcode 앱 전체는 필요하지 않습니다. 저장소 폴더에서 실행합니다.

```sh
./build.sh install
```

앱을 빌드하고 ad-hoc 서명한 뒤 `/Applications/LidLux.app`을 교체하고 실행합니다. 기존 LidLux 프로세스가 있으면 먼저 종료합니다. 설치·실행 없이 빌드만 하려면 `./build.sh`를 실행하세요. 결과는 `build/LidLux.app`입니다.

## 사용법

메뉴바의 태양 아이콘을 누르세요. 내장 자동 조절, 외부 자동 조절, 외부 밝기 키는 기본으로 켜져 있습니다.

**권장:** **시스템 설정 → 디스플레이 → 자동으로 밝기 조절**에서 내장 디스플레이의 자동 밝기를 끄세요. macOS와 LidLux가 동시에 밝기를 바꾸면 서로 간섭하거나 시스템의 변경을 사용자 선호로 학습할 수 있습니다.

**Lunar 또는 MonitorControl과 동시 사용은 권장하지 않습니다.** 해당 앱이 실행 중이면 메뉴와 설정 창에 충돌 경고가 표시됩니다. 다른 앱을 종료하거나 밝기 제어를 끄세요. 다른 앱의 변경도 수동 조절로 학습될 수 있습니다.

### 설정 창

- **밝기 성향:** 내장·외부 각각 −30~+30%, 기본 0. 곡선 밝기에 더하는 보정값입니다.
- **최소 밝기:** 내장 화면에 적용하며 0~30%, 기본 3%입니다.
- **반응 속도:** 느림·보통·빠름 중 선택하며 기본은 보통입니다.
- **실시간 상태와 그래프:** 조도, 현재 밝기, 학습 보정, 기본·적용 곡선과 학습 지점을 표시합니다.
- **외부 모니터:** 자동 조절, 밝기 키, 손쉬운 사용 설정, 밝기 성향, 학습 초기화, 모니터별 밝기와 충돌 경고를 제공합니다. 밝기는 마지막 읽기 또는 성공한 쓰기 기준이므로 모니터 버튼으로 바꾼 값은 다음 읽기에 반영됩니다.
- **보정값 초기화 / 기본값으로 되돌리기:** 내장 학습만 지우거나, 밝기 설정과 내장·외부 학습을 함께 초기화합니다. 기본값 복원은 자동 조절과 외부 밝기 키도 켜며, 로그인 실행 설정은 유지합니다.

설정과 학습 지점은 자동으로 저장됩니다.

### 밝기 키

**시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 LidLux를 허용하세요. LidLux 메뉴나 설정 창에서도 해당 화면을 열 수 있습니다. 권한을 주기적으로 확인하므로 허용한 뒤에는 보통 재실행할 필요가 없습니다.

커서를 외부 화면에 놓고 밝기 키(보통 F1/F2)를 누르세요. 표준 기능 키를 사용하는 설정이라면 **Fn**도 함께 누릅니다. 한 번에 **모니터 최대 밝기의 1/16(6.25%)**씩, **Option+Shift**를 함께 누르면 **1/64(약 1.56%)**씩 조절하며 모니터 정수 단위로 반올림합니다. 쓰기에 성공하면 해당 화면에 HUD가 표시됩니다.

커서가 내장 화면에 있으면 macOS의 기존 밝기 키 동작을 유지합니다. 외부 자동 조절을 꺼도 키 조절은 가능하지만, 학습하려면 자동 조절이 켜져 있어야 합니다. 모니터 선택에는 [이름 매칭 한계](#한계-및-주의-사항)가 있습니다.

## 동작 원리

```text
내장 조도 센서 → log10(lux + 1) → 평활화
  → 기본 곡선 + 밝기 성향 + 학습 보정
  → 내장 화면(DisplayServices) / 외부 모니터(DDC via IOAVService)
```

센서를 **0.5초마다** 읽고, 어두워질 때보다 밝아질 때 빠르게 반응하며 목표 밝기까지 서서히 이동합니다. 감지한 수동 조절을 학습 지점으로 저장하고, 가까운 지점은 교체하며 8개를 넘으면 가장 오래된 지점을 지웁니다. 지점 사이에서는 밝기를 보간하고 학습 범위 밖에서는 가장 가까운 지점의 보정값을 유지합니다.

센서는 **IOHIDEventSystem**, 내장 밝기는 **DisplayServices**, 외부 DDC/CI는 **IOAVService**를 사용합니다. 모두 비공개 API입니다.

## 한계 및 주의 사항

- 비공개 API는 macOS 업데이트로 동작이 깨질 수 있습니다. 모든 Mac·모니터·OS 버전의 호환성을 보장하지 않습니다. 센서나 필요한 내장 API를 초기화하지 못하면 경고 후 종료합니다.
- 업데이트·재빌드로 ad-hoc 서명이 바뀌면 손쉬운 사용 권한을 다시 줘야 할 수 있습니다. 권한 목록에서 기존 LidLux를 제거한 뒤 새 `/Applications/LidLux.app`을 추가하세요.
- 외부 모니터가 여러 대면 DDC 서비스와 화면 이름을 정확히 대응하지 못할 수 있습니다. 키 조절은 이름이 일치하는 모니터를 선택하며, 일치하는 이름이 없으면 **감지된 외부 모니터 모두**를 조절합니다. 이름이 같아도 여러 대가 선택될 수 있습니다. 이때 HUD는 마지막으로 쓰기에 성공한 모니터의 밝기를 표시합니다.
- 수동 조절은 밝기 변화로 추정하며 내장 학습은 최근 사용자 활동도 확인합니다. 따라서 다른 밝기 앱이 학습값에 영향을 줄 수 있습니다. 외부 모니터 버튼 조절은 즉시가 아니라 다음 DDC 읽기에서 학습합니다.
- 덮개를 닫으면 센서가 가려져 자동 조절을 멈춥니다. 클램쉘 상태에서는 조도 기반 자동 밝기를 제공하지 않습니다.

## 문제 해결

### 로그 보기

```sh
/usr/bin/log show --last 1h --predicate 'subsystem == "com.ntoktok.lidlux"'
```

zsh의 `log` 내장 명령과 macOS 로그 명령이 충돌하므로 **`/usr/bin/log` 전체 경로를 사용해야 합니다.**

### 외부 모니터가 감지되지 않거나 밝기를 읽지 못할 때

모니터 OSD에서 **DDC/CI**를 켜세요. 케이블·어댑터·독을 확인하고, 가능하면 직접 연결하거나 다른 연결 방식을 시도하세요. 특히 HDMI는 기종별 제약이 있습니다. 모니터를 다시 연결하면 재탐색합니다. LidLux의 모니터 상태와 로그에서 DDC 오류를 확인하고 다른 밝기 제어 앱은 종료하세요.

### 밝기 키가 작동하지 않을 때

**밝기 키로 외부 모니터 조절**을 켜고, 커서를 외부 화면에 놓은 뒤 LidLux가 해당 모니터의 밝기를 읽을 수 있는지 확인하세요. **손쉬운 사용** 권한을 확인하고 필요하면 **Fn**도 함께 누르세요. 업데이트나 재빌드 후 권한이 켜져 있는데도 작동하지 않으면 목록에서 LidLux를 제거하고 현재 앱을 다시 추가하세요.

## 개발

Swift Package Manager, AppKit, SwiftUI를 사용합니다.

```text
Sources/LidLux/
  main.swift                          메뉴바, 로그인 실행, 시스템 이벤트
  BrightnessController.swift          센서 샘플링, 내장 제어와 학습
  ExternalDisplays.swift              직렬 큐의 DDC/CI 탐색·읽기·쓰기
  ExternalBrightnessController.swift  외부 제어, 학습, 충돌 감지
  LearnedCurve.swift                  학습 지점과 밝기 보간
  BrightnessKeyTap.swift              키 가로채기, 손쉬운 사용 권한, 화면 선택
  BrightnessHUD.swift                 외부 밝기 HUD
  Settings.swift                      설정 저장과 적용 곡선
  SettingsWindow.swift                설정 UI, 메뉴 슬라이더, 곡선 미리보기
  Localization.swift                  영어·한국어 UI 문자열
  PrivateAPI.swift                    센서와 내장 디스플레이 API 래퍼
Tests/LidLuxTests/                     학습 곡선·현지화 테스트
Package.swift                         Swift 패키지와 최소 macOS 버전
build.sh                              앱 번들, 서명, 선택적 설치·ZIP 생성
scripts/test.sh                       Command Line Tools·Xcode 환경 테스트
scripts/make-icon.swift               아이콘 그리기
scripts/make-icon.sh                  아이콘 크기 변환과 ICNS 생성
Resources/AppIcon.icns                 앱에 포함하는 아이콘
```

앱을 실행하지 않고 테스트합니다.

```sh
./scripts/test.sh
```

[CI](https://github.com/n3wr1ch/lidlux/actions/workflows/ci.yml)는 `main` 푸시와 풀 리퀘스트에서 `macos-15`로 테스트·빌드를 실행하고 번들 메타데이터, 실행 파일, 아이콘, 서명을 확인합니다. 태그 기반 릴리스 절차와 ZIP·체크섬 산출물은 [RELEASING.md](RELEASING.md)를 참고하세요.

아이콘 디자인을 바꾼 뒤에는 다시 생성하고 빌드합니다.

```sh
./scripts/make-icon.sh
./build.sh
```
